# LinkBridge 0.0.4-beta.1 公测

提供 Windows 11 x64 + Apple Silicon Mac（macOS 15+）双机公测安装包、详细使用说明、WorkBuddy/Codex 等本地 agent 的安装交接和对应源码。

- 新增可配置双机屏幕布局：屏幕识别、四方向接缝、范围和停留、双端同步、保存及恢复。
- 收拢公测范围为键鼠、布局、文字/PNG 剪贴板及双向文件复制粘贴；新用户默认关闭媒体共享。
- 更新双端自带运行时安装包、中文配对助手和版本元数据；补充 PowerShell 5.1 与 Mac agent 安装脚本及完整性检查。
- 本轮完成双端安装和自动传输回归，实际结果和未测范围见同目录 verification.zh-CN.md。

完整朋友试用包解压后打开 `00-先读我.html`。让 agent 安装时复制 `04-Agent/给Agent的安装指令.txt`。Mac 未公证、Windows 未做发布者签名；系统提示需要本人审核。不同 Mac 签名要求不会自动覆盖。

新客户原生操作、屏幕/输入法组合、休眠重启与长期稳定性仍需实测。音视频、窗口跨屏、高级多机、Linux、Intel Mac 和 Windows ARM 不在本轮范围。每组电脑生成自己的私有配对配置，不含开发者账号或密钥。
