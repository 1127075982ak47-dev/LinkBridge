# LinkBridge 0.0.4-beta.1 发布前测试报告

日期：2026-11-07。目标：一台 Windows x64 主控 + 一台 Apple Silicon Mac 的局域网双机公测。记录区分自动协议测试、隔离安装启动和实际人工操作，不把开发电脑已有授权当作新客户完成授权。

## 构建与交付

- Windows x64 自带 .NET 10.0.11 运行时；中文 NSIS 安装器，版本 0.0.4.0、公测标签 0.0.4-beta.1。
- Mac arm64 在真实 Mac 原生编译，自带 .NET 10.0.14 运行时，ad-hoc 签名；严格深度签名校验通过。
- Mac ZIP 已在 Mac 解压后重新逐项核对 17 个文件并验证应用签名。
- 独立白名单源码快照 Release 构建通过，0 错误。辅助 DeviceProbe 有 9 条既有 CA1416 平台可用性警告，不能称为整个解决方案零警告；发行应用的本次构建无错误。
- 包括离线 HTML/Markdown 详细手册、反馈模板、agent 交接、手动配对工具、许可证和独立源码 ZIP。

## Windows 自动与安装测试：通过

1. 布局：四方向几何、屏幕偏移、目标屏幕原点、接缝覆盖范围、错误/重叠/断开/内部边界拒绝；配对 TLS 读取和应用，错误密钥不修改布局。
2. 输入：底部布局映射、文件拖动提前释放/取消/只释放一次；配对 TLS 认证、假输入顺序、心跳、掉线释放、错误密钥、MITM/上下文拒绝、队列上限和超时。
3. 文件协议：目录/空文件/中文名称、校验及拒绝路径、失败和取消等现有 FileTransferProbe 测试组通过。
4. 剪贴板协议：文字/PNG 字节、确认回调、错误密钥、超限、无效内容、取消和不完整上传拒绝通过。
5. 发现分包及手动连接：乱序、重复、丢失、畸形消息、重放、过期、错误密钥及新请求重试通过。
6. 配置：私有 ACL、未知字段、150 次原子保存、失败保留原数据通过。
7. AppIntegrationProbe：实际 MainViewModel 方法的取消、延迟消息、状态更新、退出超时等回归通过，不启用真实媒体设备。
8. 中文和空格路径下实际安装；全部安装载荷哈希匹配；窗口启动且加载安装目录内的 coreclr.dll；正常退出通过。
9. 重复安装、保留用户自加文件、卸载移除程序且保留自加文件通过。原生产桌面快捷方式与原用户配置保留。
10. Windows PowerShell 5.1 生成同密钥双端配对文件；新配置媒体开关关闭；隔离导入保留名称、未知字段及共享偏好，并生成备份通过。

另运行了旧的 native edge 探针：进程退出码为 0，但观察到 entered=0、exited=0。**它不算实体跨屏验收通过**，未将此退出码计入有效回归结论。

## Mac 自动与安装测试：通过

- 真实 Apple Silicon Mac、macOS 27.0.1 上的布局、剪贴板协议和配置持久化探针通过。
- 文件协议最初因系统临时目录经过 /var 符号链接被保护逻辑拒绝；改用本次测试目录下的真实 TMPDIR 后全部通过。没有放宽产品的符号链接保护。
- 独立 HOME 下首次安装、重复安装、安装后严格签名核验、版本读取通过。
- 隔离配置下 GUI 进程启动，运行 7 秒后 SIGTERM 正常退出（退出码 0）。这不是新用户 Gatekeeper/TCC 授权测试。
- 人为改变测试副本签名要求后，安装器拒绝覆盖通过；用户原桌面应用没有被替换或重签。

## 跨系统测试：通过

Windows SChannel → Mac SecureTransport 的真实 TLS 互操作，通过独立 SSH 转发测试 2,000 条模拟输入、心跳与一次断开释放。此项不注入真实键鼠，也不证明朋友网络的生产端口已经放行。

## 当前仍需朋友首次实机验收

- 一台全新 Windows / Mac 上的下载隔离、SmartScreen、Gatekeeper 和首次辅助功能/本地网络授权。
- 朋友自己的真实屏幕布局、混合 DPI、输入法、四方向实体穿越及多块 Mac 显示器。
- 新客户完整 Explorer/Finder 双向原生复制粘贴和最终落盘；本轮没有在用户真实剪贴板中执行这套完整流程。
- 实际断网重连、休眠唤醒、系统重启、多人不同设备及长时间运行压力。
- macOS 15/16 等其他受支持版本没有本轮实机覆盖；Windows ARM、Intel Mac、Linux 不在范围。
- 不同 ad-hoc 签名要求之间的无感升级不支持；Mac 安装器会拒绝强行替换。

媒体、原生摄像头/麦克风、应用窗口跨屏、高级多机不是本轮验收目标，不可宣传为已完成。

## 包完整性与隐私

最终 agent 路线也实际执行：Windows PowerShell 5.1 预检、静默安装、安装后全载荷校验和卸载通过；Mac 在独立 HOME 中通过完整总包哈希核验、解压和 agent 安装流程。普通用户仍须在自己的真实系统完成首次授权。Windows 配对导入器的默认相邻文件路径也已复验。

发行物由明确文件清单构成；没有打包开发目录中的真实凭据、用户 settings.json、配对密钥、证书私钥或原始私人日志。源码扫描未发现私钥块或写死的 32 位配对密钥。配对由每位朋友在自己的电脑上生成。

总包附 PACKAGE-MANIFEST.json、SHA256SUMS.txt 和总 ZIP 外部 SHA-256。清单用于检测文件变化，不替代发布者签名。本次未进行 Apple 公证或 Windows Authenticode 签名。
